# PPPL PDF Splitter (Windows Desktop)

## What this app does
- Upload a merged ERP invoice PDF
- Detect invoice numbers
- Split the PDF into invoice PDFs (optional)
- Generate an ASN ZIP file (optional)
- Save all outputs into the selected output folder (no subfolders)

✅ No OCR is used. Text must be selectable in the PDF.

---

## Requirements
- Windows PC
- Python 3.10+
- During Python install, enable: **Add Python to PATH**
